# PWA base de 4adra — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir la PWA Angular en `web/`, servida por el Worker `4adra` en `https://4adra.edier.me`. Incluye login con Google, aviso de invitación, perfil editable, política de privacidad, instalable y offline.

**Architecture:** El build de `web/` reemplaza a `backend/public` como Static Assets del Worker, todo en el mismo origen. El login usa `HttpClient` contra los endpoints de Better Auth. En desarrollo, `ng serve` en `localhost:4200` usa un proxy de `/api` hacia `wrangler dev` (`localhost:8787`) y `TRUSTED_ORIGINS`.

**Tech Stack:** Angular 22 (standalone, signals, zoneless), Angular Material 3, `@angular/service-worker`, Vitest (runner por defecto) y angular-eslint. En el backend, Hono, Better Auth y Wrangler, sin cambios de stack.

**Spec:** `docs/superpowers/specs/2026-11-11-pwa-base-design.md`

## Global Constraints

- Interfaz **solo en español**. Todo texto visible sale de `web/src/app/shared/texts.ts`; no hay literales en las plantillas.
- **No se pide ni se guarda número de teléfono** en ninguna parte.
- Rutas: `/` (Inicio), `/entrar`, `/perfil`, `/privacidad` y `**` (No encontrado).
- Punto de corte de 840 px. Por debajo: barra inferior con Inicio y Perfil. Desde 840: *navigation rail*. Pie con "Privacidad" siempre.
- API con rutas relativas (`/api/...`). El cliente nunca lee ni guarda tokens.
- Login: `POST /api/auth/sign-in/social` con `{ provider: 'google', callbackURL: '/', errorCallbackURL: '/entrar' }`.
- `?error=NOT_INVITED` → "Necesitas una invitación para usar 4adra. Pídele acceso a quien te recomendó la app.". Cualquier otro error → "No se pudo iniciar sesión. Intenta de nuevo.".
- Monedas COP/USD/EUR/MXN/GTQ, idiomas es/en y zona IANA.
- El service worker **nunca** cachea `/api/*`.
- Contacto de privacidad: `privacidad@edier.me`.
- Cobertura de `web/src/app` de al menos 70 %. TypeScript estricto. Nombres prohibidos: `Manager`, `Helper`, `Util(s)`, `Common`, `Data`, `Misc`.
- Git Flow: rama `feature/pwa-base` y PR a `develop`. Sin push a `main`.

## Review Focus

1. **Sesión que vence a mitad de uso** (un 401 en cualquier llamada de `/api/v1`): se navega a `/entrar` sin dejar la UI rota ni en bucle. Lo cubre la Task 3 (interceptor).
2. **El usuario cancela en Google o Better Auth devuelve un error distinto a `NOT_INVITED`:** se muestra el mensaje genérico, no una pantalla en blanco ni JSON. Lo cubre la Task 4 (login), y la Task 1 verifica que la redirección llegue a `/entrar`.
3. **Deep link directo a `/perfil` o `/privacidad` en producción** (recarga del navegador): el Worker devuelve la SPA, no un 404. Lo cubre la Task 7 (prueba de humo).
4. **Sin conexión con la app instalada:** abre desde la caché, muestra el aviso y no sirve respuestas `/api` cacheadas. Lo cubre la Task 6 (`ngsw-config` y banner).
5. **Guardar el perfil con un valor que el backend rechaza:** el error aparece junto al campo correcto y el formulario no pierde lo escrito. Lo cubre la Task 5.
